# Singlife POGIS - Unicorn Prize Wheel

A static prize wheel for the Unicorn event. The wheel always keeps the same 14 segments after every spin:

- Unicorn Tumbler
- Unicorn Tote Bag
- Bao Zi Lin TCM Voucher
- Complimentary Family Wealth Consultation

## Run Locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Publish On GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, `README.md`, and the `assets` folder.
3. In GitHub, open **Settings > Pages**.
4. Set the source to the `main` branch and `/root`.
5. Save, then open the published GitHub Pages link.

## Customize

Prize labels and quantities are in `script.js`. The center logo is `Unicorn logo.jpg`.
