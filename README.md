# Singlife POGIS Prize Wheel

A static prize wheel for the Unicorn event. The wheel always keeps the same 16 segments after every spin:

- Unicorn Tumbler
- Unicorn Tote Bag
- BZL TCM Voucher $10
- Complimentary Family Wealth Consultation

## Run Locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Publish On GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, `README.md`, `Unicorn logo.jpg`, and `singlife-logo.png`.
3. In GitHub, open **Settings > Pages**.
4. Set the source to the `main` branch and `/root`.
5. Save, then open the published GitHub Pages link.

## Customize

Prize labels, quantities, and named color sets are in `script.js`. Set `activeColorCombo` to `"Color Combo 1"` or `"Color Combo 2"` to switch the wheel colors. Color Combo 2 uses Singlife Red, Teal, Mandarin, and Berry. The center logo is `Unicorn logo.jpg`, and the header logo is `singlife-logo.png`.
